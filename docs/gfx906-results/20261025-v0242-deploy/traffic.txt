# Live traffic around the deploy and the archive copy (read-only `/metrics` on port 8082, 2026-10-25 UTC)

The engine running during this whole window was the **old** v0.1.45 binary (`1ba389de…`): the install
replaced the file on disk, and no process was restarted. Nothing here is a workload result for v0.2.4.2+.

Fields come from `/metrics` `requests[]`: `decode_tok_s`, `prompt_read` (new prompt tokens, i.e. no KV
reuse counted), `reused`, `prompt_total`, `prompt_ms`.
* **real prefill** = new prompt tokens / prompt seconds.
* **effective** = the whole prompt / prompt seconds, reused K/V counted. It shows how fast a warm turn is
  accepted and is not compute throughput.
