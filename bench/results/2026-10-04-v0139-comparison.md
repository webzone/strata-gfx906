## 3. Conclusions & Insights

1. **Upstream Native Support Viability**: Upstream PR #638's HIP compatibility layer successfully enables gfx906 operation on ROCm 7.x, achieving full multi-GPU pipeline splitting (`--layer-split 24`) and MTP speculative decoding.
2. **Speed Comparison**: Upstream native support demonstrates a slight throughput advantage:
   - ~5-6% higher prompt prefill throughput.
   - ~7.5-13% higher decode throughput on longer sequences / code generation.
3. **Upstream Build Fixes Required**: As delivered in upstream `v0.1.39`, several compilation issues existed on gfx906 (macro handling with template arguments in `fused_gr.cu` and missing shared memory carveout definitions), which were resolved during this synchronization.
